# 🍽️ Zomato Data Analysis & Power BI Dashboard

An end-to-end data analysis project using **Python, Pandas, and Power BI** to clean, analyze, and visualize Zomato restaurant data.

The project transforms raw restaurant data into an interactive **3-page Power BI dashboard** that helps understand restaurant ratings, customer engagement, pricing, locations, cuisines, and ordering behavior.

---

## 📌 Project Overview

The objective of this project is to analyze Zomato restaurant data and extract meaningful business insights from a large, messy dataset.

The workflow covers:

**Raw Data → Data Cleaning → Exploratory Analysis → Power BI → Interactive Dashboard → Business Insights**

The original dataset contained approximately **57K+ records**. After data cleaning and preprocessing, the final analysis dataset contained **41,665 records and 17 columns**.

## 🧹 Data Cleaning

The raw dataset required several preprocessing steps before visualization.

Key cleaning tasks included:

* Handling missing values
* Removing unnecessary/duplicate records
* Cleaning restaurant ratings
* Converting cost-related fields into usable numeric values
* Standardizing categorical values
* Cleaning restaurant and cuisine information
* Preparing the dataset for Power BI analysis

The cleaning process was performed using **Python and Pandas**.

## 💡 Key Insights

The analysis helps identify patterns such as:

* How restaurant ratings are distributed across the dataset
* Which locations have a higher concentration of restaurants
* The relationship between restaurant pricing and customer engagement
* The popularity of different restaurant types and cuisines
* The availability of online ordering and table-booking services
* Restaurants and categories receiving higher customer engagement

These insights can help restaurants understand **customer preferences, pricing patterns, and competitive positioning**.
